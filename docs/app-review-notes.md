# Animate AV App Review Notes

This document is intentionally public-safe.

Working App Review notes are private release material and must not be maintained
in this public repository. They can contain reviewer access instructions, promo
codes, backend availability notes, account deletion specifics, purchase setup,
provider limitations, legal/privacy wording, and other operational details that
belong in the private AVALSYS suite.

## Public Rule

Do not add any of the following here:

- reviewer accounts, passwords, promo codes, or campaign instructions;
- production backend URLs or provider/model details;
- pricing, credit grants, subscription setup, or RevenueCat configuration;
- internal App Store Connect notes or reviewer responses;
- user media, generated videos, receipts, request IDs, or logs.

Use the private Animate AV release package for the actual App Store Connect
review notes.
